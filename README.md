# VOC Research World — Website Starter

This is a static starter site for publishing scientific educational content.

## Files
- `index.html` — site structure and pages
- `style.css` — responsive visual design
- `script.js` — search, category filtering and browser-based publishing
- `logo.svg` — editable vector logo
- `README.md` — this guide

## Important
The current Publish form saves articles in the visitor's browser using localStorage. It is NOT yet a real public CMS.

For a production website, the next version should add:
1. A real domain (e.g. vocresearchworld.com if available).
2. Hosting.
3. A database/CMS for articles.
4. Secure admin login.
5. Image/file storage.
6. SEO metadata and sitemap.
7. Citation/reference handling.
8. Analytics.
9. Backups and moderation.

## Suggested publishing model
Use a public website for readers and a protected `/admin` area for you. Articles should have title, slug, category, abstract, body, references, author, publication date, featured image and status (draft/published).

## Scientific editorial standard
Every research/health-related article should distinguish established findings from preliminary evidence, cite primary or authoritative sources, state limitations, and avoid unsupported clinical claims.
